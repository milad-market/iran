# Gemini & Antigravity Agent Configuration: UI/UX Pro Max

The **UI/UX Pro Max** skill is installed in `.agents/skills/` and `.gemini/skills/`.

### Design Guidelines & Query Engine
Whenever designing or refining components, layouts, typography, or color themes, query the bundled intelligence engine:
```bash
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "<query>" --domain <domain> --stack react
```

- High aesthetic precision, optical balance, and anti-slop rules.
- WCAG AA accessibility and responsive ergonomic scaling.
- Professional typographic pairings and theme tokenization.
